Conceptos Clave · ¡Haz clic para voltear!

👆 Toca las tarjetas para descubrir el mundo del código
📋
Algoritmo
Pasos ordenados para resolver algo
Es la receta de la programación: entrada → proceso → salida. Si cambias el orden, cambia el resultado.
🧱
Scratch
Programar con bloques
Plataforma gratuita del MIT donde programas arrastrando bloques como piezas de rompecabezas. Ideal para empezar.
🔁
Ciclo o Bucle
Repetir sin repetir el código
"Repetir 10 veces" ejecuta el bloque 10 veces. Sin condición de salida, se vuelve un bucle infinito.
📦
Variable
Una caja que guarda un valor
Guarda datos que pueden cambiar: puntuación, temperatura, humedad. Se puede crear, asignar y actualizar.
🚦
Condición (SI...)
Tomar decisiones en el código
"SI humedad < 30% ENTONCES encender bomba". El programa decide solo según los datos que recibe.
🗄️
Base de Datos
Información organizada en tablas
Filas = registros, columnas = campos. Un campo clave (ID) nunca se repite ni queda vacío.

🗝️ Secretos del Mundo del Código

¿Sabías que...

👩‍💻
La primera programadora fue una mujer: Ada Lovelace escribió el primer algoritmo en 1843, más de 100 años antes de que existieran los computadores modernos. 💫
🐛
El "bug" viene de una polilla real: En 1947 una polilla quedó atrapada en el computador Harvard Mark II. Desde entonces los errores se llaman bugs y arreglarlos, debugging. 🦟
🇨🇴
Colombia programa desde el campo: Proyectos de agricultura de datos usan sensores de humedad como el que acabas de manejar, para regar café y arroz con menos agua. ☕
🧒
Scratch lo crearon para niños: Nació en el MIT en 2007 y hoy tiene más de 100 millones de proyectos compartidos. Tu primer programa ya está entre ellos. 🌎
