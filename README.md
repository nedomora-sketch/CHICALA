# 🌱 Sembrando Conocimiento en Chichalá

Proyecto educativo interactivo para la 
IE Técnica Camacho Angarita, Sede Chichalá.
Corregimiento El Limón · Vereda Providencia · Chaparral, Tolima.

## 🎯 Descripción

Menú de aprendizaje interactivo diseñado para estudiantes 
de Básica Primaria y Secundaria de la Sede Chichalá, 
con contenidos organizados por grados, períodos y semanas.

## 📚 Áreas y Grados

| Área | Grados |
|------|--------|
| 🔢 Matemáticas | 3°, 4° y 5° |
| 💻 Tecnología | 3°, 4°, 5°, 6°, 7°, 8° y 9° |
| 🌎 Inglés | 6°, 7°, 8° y 9° |
| 🚀 Emprendimiento | 6°, 7°, 8° y 9° |

## 🗂️ Estructura del Proyecto
CHICALA/ ├── index.html ├── css/ │ └── styles.css ├── js/ │ └── main.js └── asignaturas/ ├── matematicas.html ├── tecnologia-pri.html ├── tecnologia-sec.html ├── ingles.html └── emprendimiento.html


## ✨ Características

- 🎮 Diseño tipo juego/aventura con mundos por nivel
- 🎬 Animaciones secuenciales tipo presentación
- 📱 100% Responsive (móvil, tablet y escritorio)
- 🎨 Paleta de colores motivadora y alegre
- 📅 Acordeón de 4 períodos × 8 semanas por asignatura
- 🔄 Selector dinámico de grado sin recargar la página
- 📖 Contenido basado en mallas curriculares oficiales
